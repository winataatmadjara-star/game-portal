Manajemen Sinkronisasi GitHub & Setup Lokal

🐙 Kelola sinkronisasi kode secara dua arah (Pull & Push) langsung dari panel web serta panduan inisialisasi Git di komputer lokal Anda.
Masukkan URL remote git (Contoh: https://github.com/username/repo.git)
Jika Anda baru pertama kali menghubungkan folder proyek lokal ke repository GitHub di atas, jalankan perintah terminal berikut secara berurutan:
1. Masuk ke folder proyek lokal Anda & Inisialisasi Git:
cd /path/ke/folder/proyek && git init
2. Hubungkan folder lokal ke Remote Repository GitHub:
git remote add origin https://github.com/username/game_portal.git
3. Buat commit awal & Push ke branch utama (main):
git add . && git commit -m "feat: initial commit gameportal" && git branch -M main && git push -u origin main
> Siap menjalankan perintah Git...
